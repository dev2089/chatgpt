# VibeBuilder AI Platform

A free, unlimited vibe-coding web app that lets users:

- Generate starter websites from prompts
- Edit project files directly
- Preview websites live
- Create/delete files in a mini file manager
- Publish shareable versions locally

## Run

Open `index.html` in any modern browser.

## Notes

This is a client-side prototype. Published links are stored in browser `localStorage`, so they work on the same browser/device profile.
